## About This Repository

This repository documents my work, notes, exercises, and projects for ART 46: 2-D Visual Design.

The course explores fundamental elements of two-dimensional design, including line, shape, color, texture, value, space, scale, balance, proportion, repetition, contrast, harmony, unity, emphasis, and visual movement.

A major focus of the course is graphic narrative and sequential art, including:

- Character development
- Pacing
- Panel composition
- Page layout
- Text-image relationships
- Visual continuity
- Comics and visual storytelling
